This module is an extension for *connector_prestashop*. With it, you
will be able to manage your catalog directly from Odoo:

- Create/modify attributes and values in Odoo and push them in
  PrestaShop.
- Create/modify products and push them in PrestaShop.
- Create/modify products variants and push them in PrestaShop
  (combinations).
- Create/modify categories and push them in PrestaShop.
- Create/modify images and push them in PrestaShop.
